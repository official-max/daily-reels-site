Privacy Policy

daily-reels · Last updated 21 November 2026

Who uses this app

daily-reels is a personal automation used only by its owner for their own YouTube channel. No other users sign in to it.

What Google data it accesses

  • YouTube upload (youtube.upload): to upload the videos the tool creates to the owner's channel and set their publish time.
  • YouTube read-only (youtube.readonly): to read the list of popular public videos in India, used only as topic ideas.

How the data is stored

The only Google credential kept is the owner's OAuth refresh token. It is stored as an encrypted secret in the owner's GitHub account and is used only to make the uploads above. No personal information, channel data or viewer data is collected, sold or shared with anyone.

Google API Services User Data Policy

daily-reels' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions.
